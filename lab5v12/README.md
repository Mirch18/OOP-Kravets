# Лабораторна робота №5

**Тема:** Поліморфізм: динамічне зв'язування та перевизначення методів.

**Мета:** Навчитися реалізовувати поліморфну поведінку за допомогою віртуальних методів та їх перевизначення, а також агрегувати результати поліморфних викликів (варіант 12: ієрархія `MediaFile → AudioFile, VideoFile, ImageFile`).

## Хід роботи

У ході виконання роботи за допомогою .NET CLI у директорії `OOP-Kravets` було створено консольний проєкт `lab5v12`.

У файлі `Program.cs` реалізовано ієрархію класів, що містить:

- **Базовий клас `MediaFile`:** властивість `FileName`, конструктор та віртуальний метод `Open()`.
- **Похідний клас `AudioFile`:** властивість `BitRate`, конструктор і перевизначений метод `Open()`, який відкриває аудіо-файл.
- **Похідний клас `VideoFile`:** властивість `Resolution`, конструктор і перевизначений метод `Open()`, який відкриває відео-файл.
- **Похідний клас `ImageFile`:** властивість `Dimensions`, конструктор і перевизначений метод `Open()`, який відкриває зображення.

У точці входу `Main`:

1. Створено колекцію `List<MediaFile>` базового типу.
2. До колекції додано екземпляри `AudioFile`, `VideoFile` та `ImageFile`.
3. У циклі для кожного об'єкта викликано віртуальний метод `Open()`.
4. Завдяки динамічному зв'язуванню для кожного об'єкта виконується відповідна реалізація методу похідного класу.
5. Результати викликів агреговано у список відкритих файлів і підраховано їх загальну кількість.

## Відповіді на контрольні запитання

1. **Що таке поліморфізм і як він реалізується в C# за допомогою `virtual` та `override`?**

   Поліморфізм — це здатність об'єктів різних класів реагувати на однаковий виклик по-різному залежно від їхнього фактичного типу. У C# метод базового класу позначається ключовим словом `virtual`, а похідний клас надає власну реалізацію за допомогою `override`. У роботі виклик `Open()` через посилання типу `MediaFile` виконує реалізацію `AudioFile`, `VideoFile` або `ImageFile`.

2. **Поясніть поняття динамічного зв'язування. Чим воно відрізняється від статичного?**

   Динамічне зв'язування означає, що конкретна реалізація віртуального методу визначається під час виконання програми за фактичним типом об'єкта. Статичне зв'язування визначає метод під час компіляції за типом посилання. Наприклад, посилання `MediaFile` може містити об'єкт `VideoFile`, тому під час виконання буде викликано `VideoFile.Open()`.

3. **Наведіть приклад, як поліморфізм дозволяє писати більш гнучкий та розширюваний код.**

   Цикл у `Main` працює з колекцією `List<MediaFile>` і не перевіряє тип кожного елемента через `if` або `switch`. Якщо додати новий похідний клас, наприклад `AnimationFile`, достатньо реалізувати в ньому метод `Open()`, а код обходу колекції залишиться без змін.

4. **Які переваги дає використання колекцій базових типів для роботи з поліморфними об'єктами?**

   Колекція базового типу дає змогу зберігати об'єкти різних похідних класів в одному списку, обробляти їх єдиним алгоритмом і зменшувати дублювання коду. Водночас завдяки віртуальним методам кожен об'єкт зберігає власну специфічну поведінку.
